Welcome! This page provides an overview of hands-on tutorials for the Bigraph Framework:

- [**Bigraph Modelling Exercises**](/tutorials/exercises): practice core bigraph modelling concepts through small exercises.
- [**Vending Machine**](/tutorials/vending): model an appliance as a reactive system with a web interface.
- [**ROS2 Streaming & Conditional Rules**](/tutorials/streamattributes): stream ROS2 data into bigraph node attributes, persist models with CDO, and apply conditional rewriting rules.
- [**Self-sorting Robots**](/tutorials/ssr): define a coordination protocol as bigraphs for self-sorting robots (physical bubble sort).
